# RINGANA Assistant V10.7

Fecha de release: 2026-07-28

El frontend permanece técnicamente compatible con V10.6.

V10.7 incorpora como componente principal externo:

- RINGANA_QUEUE_WORKER
- Cola persistente PostgreSQL
- Reserva FIFO atómica
- Procesamiento secuencial Playwright
- Actualización de estados en PostgreSQL
- Notificación WF04 por WhatsApp
- Arranque automático mediante Programador de tareas
- Cuarentena de leads anteriores incompletos

El tag V10.6 preserva la versión anterior del frontend.
